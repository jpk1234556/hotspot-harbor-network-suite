# NetBill Africa roadmap

- [x] Stage 1 — Foundation: auth, businesses, roles, schema + per-business security, console shell, dashboard, settings, audit log, sample data
- [ ] Stage 2 — Billing core: packages, speed profiles, vouchers (bulk/QR/PDF/CSV), customers CRM, payments, revenue reports
- [ ] Stage 3 — Network: routers (encrypted creds, test connection, provisioning), APs, live clients, RADIUS
- [ ] Stage 4 — Money & messaging: mobile money gateways, SMS/WhatsApp, captive portal, customer portal (needs provider credentials)
- [ ] Stage 5 — Agents, invoices, reports export, alerts, subscriptions, Super Admin console
- [ ] Stage 6 — Hardening: rate limits, MFA, security review, docs
